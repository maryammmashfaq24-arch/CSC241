1) INVALID OVERLOAD - two methods differing only by return type
Code attempted inside OverloadDemo.java:
    void enroll(String courseCode) { ... }
    int  enroll(String courseCode) { return 0; }

javac message:
OverloadDemo.java:17: error: method enroll(String) is already defined in class OverloadDemo
    int enroll(String courseCode) {
        ^
1 error

Reason: the return type is NOT part of a method's signature, so both
methods have the same signature enroll(String) and the compiler cannot
tell them apart. Fix applied: the int version was removed.
